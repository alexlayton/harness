# Harness 0.10.2

This is a small release. It fixes prompt caching for Codex, adds a setting for
reasoning summaries, and makes a few changes that help models spend fewer
tokens.

## Fixes

- Codex requests now send the session ID as `prompt_cache_key` and as a
  `session-id` header, so the provider can reuse its prompt cache across the
  turns of a session.

## Changes

- New `reasoning_summary` setting (`auto`, `concise`, `detailed`, or `none`) for
  OpenAI Responses and Codex models. When it is not set, interactive frontends
  use `auto`, and `harness prompt` uses `none` unless `-v` is passed. Compaction
  and subagents never ask for summaries. See
  [Configuration](../configuration.md#basic-settings).
- `read` adds a note when a range is read again and its content has not changed
  since the last read in the session. Subagents do not add this note.
- The `subagent` tool description now says not to delegate work that one or two
  direct tool calls can do, or files that are already in the context. The tool
  guidance also encourages batching independent read-only calls.

## Diagnostics

- Each model request logs its connect time, time to first event, total time, and
  output tokens.
- Harness logs a warning when a session that has already made several requests
  reports zero cached tokens, which usually means that prompt caching is broken.

## Installation and upgrade

Run `harness update` after 0.10.2 is published. The supported CLI builds are:

- macOS on Apple silicon (`aarch64-apple-darwin`).
- macOS on Intel (`x86_64-apple-darwin`).
- Linux x86-64 with glibc 2.35 or newer (`x86_64-unknown-linux-gnu`).
- Linux arm64 with glibc 2.35 or newer (`aarch64-unknown-linux-gnu`).

Each archive includes the binary, README, header image, and MIT license. Use the
attached `SHA256SUMS` file to verify a downloaded archive, and
`gh attestation verify` to check its build provenance.

To install this version with the installer:

```sh
curl -fsSL https://raw.githubusercontent.com/alexlayton/harness/main/install.sh \
  | bash -s -- --version v0.10.2
```

The Python API is still a source-installed MVP. This release does not publish a
PyPI package or prebuilt wheels:

```text
harness-agent @ git+https://github.com/alexlayton/harness.git@v0.10.2
```

Harness still runs tools without confirmation. Bash and MCP tools have the
access of the operating-system user. Use these features only in environments
where you accept that behavior.
