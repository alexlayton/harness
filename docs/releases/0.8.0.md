# Harness 0.8.0

This release adds prewalk handoff, a Claude subscription provider, and
OpenAI-compatible endpoints. It renames code mode to `codemode` and makes it
use far fewer tokens. It also adds build provenance attestations and many
reliability fixes.

## Prewalk

Prewalk hands work from the planning model to a faster or cheaper target model.
The planning model investigates, writes a short plan, and makes the first
change. After the first `edit` or `write` round, Harness switches to the target
model, which continues the plan.

```toml
[prewalk]
enabled = true
model = "openrouter:openai/<small-model>"
reasoning_effort = "low"
```

In the terminal UI, use `/prewalk`, `/prewalk-model`, and `/prewalk-reasoning`.
On the command line, use `--prewalk`, `--prewalk-model`, and
`--prewalk-reasoning-effort`. The Python API has matching `prewalk`,
`prewalk_model`, and `prewalk_reasoning_effort` options. ACP sessions do not
arm prewalk. See [Prewalk](https://github.com/alexlayton/harness/blob/v0.8.0/docs/configuration.md#prewalk).

## Anthropic Claude provider

Use a Claude subscription with browser login:

```text
harness login anthropic-claude
harness --provider anthropic-claude
```

**This is an unofficial subscription protocol. It can violate provider terms
and put your account at risk.** Harness does not fall back to API-key billing.
The release also adds newer Claude models, reasoning support, and model-specific
context limits. The older names `anthropic-subscription` and `claude-sub` still
work, and saved credentials remain valid.

## OpenAI-compatible endpoints

Define a provider under `[providers.<name>]` to use any server that supports
the Chat Completions API, for example LM Studio, Ollama, or vLLM:

```toml
provider = "lmstudio"

[providers.lmstudio]
type = "openai-compatible"
base_url = "http://localhost:1234/v1"
```

Use `/model <provider>:<model>` to switch. See
[Providers](https://github.com/alexlayton/harness/blob/v0.8.0/docs/providers.md#openai-compatible-endpoints)
for headers, API keys, and context window settings.

## Codemode

**The `run_code` tool is now `codemode`.** Use `[codemode]` in `config.toml`.
The old `[code_mode]` table is still read, and old sessions still replay.

The tool description now holds a compact index of tools. Full descriptions and
schemas load on demand through `TOOLS`, `describe(name)`, and `MODULES`. A
plain "hello" prompt dropped from about 23.7k to about 5.6k input tokens.

## Build provenance

Release archives now have a signed build provenance attestation. Verify one
with the GitHub CLI:

```sh
gh attestation verify harness-v0.8.0-aarch64-apple-darwin.tar.gz \
  --repo alexlayton/harness \
  --signer-workflow alexlayton/harness/.github/workflows/release.yml
```

The installer and `harness update` check checksums only. They do not check the
attestation.

## Reliability and hardening

- **Providers and auth:** Harness retries once with a refreshed token after
  HTTP 401, refreshes tokens across processes safely, and uses timeouts and
  no redirects in OAuth clients. It retries truncated streams and transient
  in-band errors.
- **Sessions:** Harness can delete sessions safely, refuses appends after the
  log is replaced, adopts sessions atomically, and skips unreadable files in
  listings with a warning.
- **Compaction and agent:** Compaction keeps valid boundaries and recovers from
  context overflow. A parent turn stops after 200 tool rounds, and subagent
  context is bounded by the model window.
- **MCP and tools:** Response bodies are bounded, stdio server process trees
  stop on close, and secrets are redacted from diagnostics. Edit matching is
  linear, and grep reports incomplete searches.
- **Terminal UI:** Text is measured and edited by grapheme cluster. Streamed
  Markdown follows CommonMark fence rules. Event handling and resize are bounded
  and faster.
- **Python:** Cleanup after Ctrl-C is bounded, and a second Ctrl-C works.

## Installation and upgrade

From 0.7.0, run `harness update` after 0.8.0 is published. The supported CLI
builds are unchanged:

- macOS on Apple silicon (`aarch64-apple-darwin`).
- macOS on Intel (`x86_64-apple-darwin`).
- Linux x86-64 with glibc 2.35 or newer (`x86_64-unknown-linux-gnu`).

Each archive includes the binary, README, header image, and MIT license. Use the
attached `SHA256SUMS` file to verify a downloaded archive.

To install this version with the installer:

```sh
curl -fsSL https://raw.githubusercontent.com/alexlayton/harness/main/install.sh \
  | bash -s -- --version v0.8.0
```

The Python API is still a source-installed MVP. This release does not publish a
PyPI package or prebuilt wheels:

```text
harness-agent @ git+https://github.com/alexlayton/harness.git@v0.8.0
```

Harness still runs tools without confirmation. Bash and MCP tools have the
access of the operating-system user. Use these features only in environments
where you accept that behavior.
